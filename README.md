# Платформер

Двухмерный платформер на **Phaser 3** без сборки. 30 уровней с нарастающей
сложностью, монеты, враги, шипы, движущиеся платформы, лава в пропастях,
звук, сохранение прогресса, тач-управление, **конструктор уровней** и
**кастомизация героя своим фото**.

Вся графика рисуется кодом — внешних картинок нет (единственное исключение —
фото героя, которое загружает сам игрок).

---

## Запуск

Игра использует ES-модули и `fetch` для загрузки уровней, поэтому открыть
`index.html` через `file://` **не получится** — нужен локальный HTTP-сервер.

```bash
python3 -m http.server 8000      # или: npx serve .
```

Открыть: **http://localhost:8000**

## Тесты

```bash
npm test
```

Встроенный `node:test` (без зависимостей) над чистой логикой:
- `test/parseLevel.test.js` — парсер ASCII-карт
- `test/progress.test.js` — логика жизней/прогресса
- `test/reachability.test.js` — **проходимость**: BFS по стенд-поинтам с учётом
  физических границ прыжка проверяет, что путь P→F существует во всех уровнях,
  что у каждого ровно один `P`/`F`, и что под траекторией каждого врага есть пол.

Ожидаемо: **11/11 пройдено**. Любое изменение `levels/*.json` прогоняется этим
тестом — добавить непроходимый уровень незаметно нельзя.

## Управление

| Контекст | Клавиатура | Тач |
|---|---|---|
| Меню | клик по уровню / `Enter` (первый) | тап по уровню |
| Движение | `←` `→` или `A` `D` | экранные кнопки ◀ ▶ (внизу слева) |
| Прыжок | `↑` / `W` / `Пробел` (стоя на земле) | кнопка ⤴ (внизу справа), удержание = повтор |
| Выход в меню (в игре) | `Esc` | кнопка `≡ Меню` в HUD |
| Уровень пройден | `Пробел` — дальше, `M` — меню | кнопки «▶ Дальше» / «≡ Меню» |
| Игра окончена | `Пробел` — заново, `M` — меню | кнопки «↻ Заново» / «≡ Меню» |
| Игра пройдена | `Пробел` / `M` — меню | кнопка «≡ В меню» |

Управление мультитач: можно держать направление и прыгать одновременно. Экран
вписывается под любой размер (Phaser `Scale.FIT`).

Звук переключается кнопкой 🔊/🔇 в меню (состояние сохраняется).

## Игровые механики

- **3 жизни** на уровень. Жизнь теряется при касании шипа, падении в лаву/яму
  или контакте с врагом сбоку.
- **Прыжок на врага сверху** убивает его, игрок отскакивает.
- **Монеты** — по 10 очков, счёт копится между уровнями. Лучший счёт за уровень
  сохраняется и показывается в меню (`★`).
- **Движущиеся платформы** везут игрока (по X и Y).
- **Лава** в пропастях — мгновенная смерть при касании; поверхность анимирована.
- **Флаг** — финиш уровня. Пройденные уровни помечаются `✓`.
- Прогресс (пройдено + рекорды) хранится в `localStorage`; сбрасывается кнопкой
  `↻ сброс` в меню.

## Уровни

30 уровней с плавной кривой сложности (порядок задаётся `levels/index.json`,
сложность подтверждена эвристикой в `test/`-анализе):

| # | Тир | Уровни |
|---|---|---|
| 1–5 | лёгкие | Первые шаги · Первый прыжок · Ступеньки · Осторожно шип · Первый враг |
| 6–10 | средние | Тропинка · Перепрыжки · Платформа · Шипы и ямы · Разогрев |
| 11–15 | продвинутые | Связка · Качели · Гребёнка · Двойной прыжок · Перед бурей |
| 16–20 | сложные | Шторм · Лавовые мосты · Гаунтлет · Башни · Эпицентр |
| 21–25 | очень сложные | Закалка · Каньоны · Марафон · Лабиринт препятствий · Цитадель |
| 26–30 | хардкор | Лавовая бездна · Море лавы · Частокол · Вертикаль · Вулкан |

## Конструктор уровней

Меню → **🔧 Открыть конструктор уровней**. Отдельная сцена с HTML-панелью справа:

- Рисование мышью: тайл / шип / монета / старт / финиш / ластик (клавиши `1`–`5`, `0`).
- Враги и движущиеся платформы — через поля панели (координаты в тайлах).
- **Загрузить уровень** — взять любой встроенный (или опубликованный) в редактор.
- **▶ Тест** — сыграть прямо сейчас; после смерти/победы вернёт в конструктор.
- **⭐ Опубликовать в меню** — уровень попадёт в меню (хранится в `localStorage`).
- **📋 Экспорт / 📥 Импорт JSON**, **💾 черновик**, изменение размера, `Esc` — выход.

## Кастомный герой (фото)

Меню → **📷 Загрузить фото героя**:
1. Выбор файла → **круглый кроп** (перетаскивание/масштаб рамки).
2. Из кропа собирается **анимированный спрайт** в мультяшном стиле (круглое
   лицо + тело + ботинки), идёт покадровая анимация ходьбы.
3. Сохраняется в `localStorage`, применяется после перезагрузки. Сбросить —
   «(вернуть стандартного)».

Подробности конвейера — в [ASSETS.md](ASSETS.md).

## Формат уровней (как добавить свой)

Уровни — JSON-файлы в `levels/`. Порядок в меню — массив имён в
`levels/index.json`.

### Карта (`map`)

Массив строк одинаковой длины (наши уровни — **78** символов). Каждая строка —
ряд тайлов.

| Символ | Объект |
|---|---|
| `=` | твёрдый тайл (земля/платформа) |
| `^` | шип (хитбокс — нижняя половина тайла) |
| `C` | монета |
| `P` | старт игрока (ровно один) |
| `F` | финишный флаг (ровно один) |
| `.` | пусто |

Колонки с полом автоматически досыпаются землёй до низу экрана; колонки-пропасти
заполняются лавой — это происходит в `GameScene` при рендере, карту менять не
нужно.

### Враги (`enemies`)

```json
{ "x": 10, "y": 6, "patrol": [8, 14] }
```
`x`,`y` — позиция в тайлах; `patrol` — `[minTileX, maxTileX]`. Под всей
траекторией патруля должен быть пол (проверяется тестом).

### Платформы (`movingPlatforms`)

```json
{ "x": 11, "y": 5, "axis": "x", "range": 4, "speed": 80 }
```
`axis` — `"x"`/`"y"`; `range` — дальность в тайлах в каждую сторону; `speed` —
px/сек.

### Добавление уровня

1. Положить `levels/L6.json` (или экспортировать из конструктора).
2. Дописать его имя в `levels/index.json`.
3. `npm test` — убедиться, что проходим.

Меню само считает число колонок под любое количество уровней.

## Чеклист ручного тестирования

- [ ] Меню: 30 уровней в колонках, `✓` и `★` у пройденных. Клик/Enter — старт.
- [ ] Движение `←/→`, прыжок `↑/W/Пробел` только стоя.
- [ ] Игрок стоит на земле, камера следует, небо голубое, плывут облака.
- [ ] Сбор монеты: исчезает, счёт растёт, звон.
- [ ] Шип / лава / враг сбоку → вспышка, жизнь −1, рестарт уровня.
- [ ] Прыжок на врага сверху → враг исчез, отскок, звук.
- [ ] Поверхность лавы анимирована; земля сплошная до низу.
- [ ] Движущаяся платформа везёт игрока (X и Y) с её скоростью.
- [ ] Флаг → «УРОВЕНЬ ПРОЙДЕН», Пробел — дальше со счётом и 3 жизнями.
- [ ] Все жизни → «ИГРА ОКОНЧЕНА», Пробел — заново, M — меню.
- [ ] Последний уровень → «ИГРА ПРОЙДЕНА», Пробел/M — меню.
- [ ] `Esc` и кнопка `≡ Меню` выходят в меню в любой момент.
- [ ] Тач: удержание половин экрана = ходьба, свайп вверх = прыжок.
- [ ] Конструктор: рисование, тест, публикация в меню, экспорт/импорт.
- [ ] Фото героя: кроп → анимированный спрайт; «вернуть стандартного» сбрасывает.
- [ ] Звук 🔊/🔇 и сброс прогресса работают; прогресс переживает перезагрузку.

## Известные ограничения

- Прогресс и пользовательские уровни/фото живут в `localStorage` одного браузера
  (не переносятся между устройствами; перенос уровней — через экспорт JSON).
- Нет фоновой музыки (только эффекты).
